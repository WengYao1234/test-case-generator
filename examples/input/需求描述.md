# 样例输入：用户登录功能

## 功能描述

实现一个 Web 应用的用户登录功能，具体需求如下：

### 登录页面
- 用户在浏览器访问 `/login` 路径，进入登录页面
- 页面包含：用户名输入框、密码输入框、「记住我」复选框、登录按钮、「忘记密码」链接
- 如果用户已登录（Session 有效），访问 `/login` 自动跳转到首页 `/home`

### 登录逻辑
- 用户名：4-20 位字母/数字/下划线，不区分大小写
- 密码：6-20 位，必须包含至少 1 个大写字母、1 个小写字母、1 个数字
- 连续 5 次输入错误密码，账号锁定 30 分钟
- 登录成功后跳转到 `/home`，显示用户名和登录时间
- 勾选「记住我」则 Session 有效期 7 天，否则 30 分钟
- 后端使用 JWT Token 认证，Token 存储在 HttpOnly Cookie 中

### 安全要求
- 密码传输使用 HTTPS 加密
- 防止暴力破解（锁定机制）
- 防止 SQL 注入
- 防止 XSS 攻击
- 登录失败不回显具体原因（统一提示「用户名或密码错误」）

### 兼容性
- 支持 Chrome、Firefox、Safari、Edge 最新两个大版本
- 移动端浏览器适配（响应式布局）
