# Phase 0: 上下文采集（总控参考）

## 用途

本文件是总控在直写 `_context.md` 时的格式参考。不再调度子Agent。

## _context.md 输出格式

```markdown
# 项目上下文

## 基本信息
- **项目/模块名称：** [名称]
- **需求类型：** [新增功能 / 变更功能 / 回归测试]
- **采集时间：** [时间]

## 技术栈
- **平台类型：** [Web / App / API / 嵌入式 / 其他]

## 测试范围
- **功能测试：** 是/否
- **非功能测试：** 是/否 — 类型（性能/安全/兼容性/易用性）

## 用户原始需求
[需求路径及概要]
```
